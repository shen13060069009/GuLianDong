安装与使用 · 免费开源版，不需要激活码

您的位置：首页 - 图文教程：安装与使用
没有激活步骤了。v1.1.2 起股联动完全免费开源，安装完直接用—— 没有激活码、没有试用期、不联网也能跑。原来的「获取激活码」步骤已全部删除。

1下载安装包

打开官网 www.gldong.com，点击首页的「下载桌面版」按钮，得到安装包 GuLianDong-Setup-1.1.2.exe（约 70 MB）。请务必从官网下载，其他渠道来源不明。

2双击安装（可选开机自启动）

双击安装包，按向导操作：选择安装目录 → 安装 → 完成页可勾选 「开机自动启动」（默认勾选，登录 Windows 后股联动自动在后台待命）和 「立即启动」。安装完成桌面自动创建快捷方式，卸载走控制面板「卸载程序」即可。

默认安装到用户目录（%LOCALAPPDATA%\Programs\GuLianDong），无需管理员权限；若想换目录，在「选择安装位置」一步修改即可。

3运行软件

双击桌面「股联动 GuLianDong」快捷方式启动（若提示权限请求，允许即可——管理员权限是框选识别全局生效的需要）。启动成功后，桌面右下角会弹出提示：

▲ 真实截图：启动成功后桌面右下角的提示，任务栏出现「股联动」托盘图标

看到托盘图标就代表已经在运行了——软件常驻后台不显示主窗口，右键托盘图标可打开菜单：勾选框选/划词开关、切换框选手势、查看版本信息、退出。

4装好行情软件，就可以用了

打开通达信 / 同花顺 / 东方财富任意一个并登录（可以是最小化）。软件会自动识别，不需要手工配置路径。到这里就全部结束了——不需要激活码，不需要登录账号，不联网也能用。

5（可选）切换框选手势

托盘图标右键 → 框选手势，可在三个组合键中切换，选择会立即生效并被记住：

  • Ctrl + Shift + 左键（默认）
  • Ctrl + Alt + 左键
  • Shift + Alt + 左键

旧版本配置过 Alt 或鼠标侧键的，会自动回退到 Ctrl+Shift。

6想自己改词库 / 看源码？

全部数据在安装目录的 data/ 文件夹：stocks.json、aliases.json、weak_names.json，自行编辑扩充即可，无需重新打包。想看完整源码，仓库在 GitHub（MIT 协议）：

git clone https://github.com/shen13060069009/GuLianDong.git
cd GuLianDong
pip install -r requirements.txt
python main.py

7联动使用教程（三步）

① 框选：打开聊天窗口（微信 / 钉钉 / 飞书 / 企业微信均可），群友聊到股票时：按住 Ctrl + Shift → 鼠标左键拖拽 → 框住股票文字 → 松开。

▲ 真实截图：在飞书聊天窗口中框选一段含股票的消息

② 弹出联动菜单：松开鼠标后，识别结果以浮动菜单出现在旁边，每只股票一行，显示名称 + 代码，右侧是联动按钮：

▲ 联动菜单特写：点击「看通达信 / 看同花顺 / 看东方财富」跳转，点击「复制」复制代码

③ 点击按钮，直达个股：前提是行情软件已登录并打开（可以是最小化）。点击对应按钮后行情软件自动弹出并跳到该股页面：

▲ 真实截图：通达信 / 同花顺 / 东方财富 自动跳转到个股页面

+技巧：多股对比浮条

?常见问题

为什么框选没反应？

请确认以管理员身份运行了 GuLianDong.exe；另外部分全屏独占游戏画面无法识别。

真的免费吗？会不会以后收费？

不会。软件已按 MIT 协议开源，授权层代码整体移除，不存在激活码、试用期与联网校验，后续版本也会继续免费开源。

支持哪些行情软件？

通达信（含各类定制版）、同花顺经典版与远航版、东方财富 PC 客户端。

数据安全吗？会联网吗？

识别全部在本机完成，不上传截图与聊天内容。免费版完全不做授权校验，软件只在你想看引流内容时才会尝试联网，拉不到也不影响任何功能。

换电脑 / 重装系统怎么办？

什么都不用做——没有机器码绑定，重新下载安装即可。
