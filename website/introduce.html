0它解决什么问题

股联动（GuLianDong）是一款运行在 Windows 桌面的股票联动工具。看盘交易的人每天在微信、钉钉、飞书、企业微信的聊天群里刷到大量股票讨论——群友说的每一只股票，过去你都要手动记住名称、切到行情软件、输入六位代码才能看到行情；而「股联动」把这个过程变成一步：框选或划词 → 点击 → 直达个股页面。

软件内置沪深京 5,500+ 只股票（含北交所）与常用简称、别名词库，聊天里打错的「谷份」「古票」也能自动纠正命中。识别引擎完全运行在本地，截图与聊天内容不上传任何服务器。

▲ 真实截图：飞书聊天窗口中框选一段消息，弹出联动菜单，点击「看通达信」直达个股

1框选识别 —— 屏幕任意位置

按住 Ctrl + Shift + 鼠标左键拖拽，框选屏幕上任意位置的股票文字——聊天记录、网页新闻、PDF 研报、截图图片，松手即识别。识别结果以浮动菜单形式出现在鼠标旁边。

▲ 真实截图：在飞书聊天窗口中框选拖拽，绿色框选区域正在覆盖目标文字

2划词联动 —— 全局可用

在微信 / 钉钉 / 飞书 / 企业微信 / QQ / 浏览器里用鼠标选中股票文字，松开即弹出联动菜单，无需快捷键。任意聊天软件通用：

▲ 真实截图：微信 / 钉钉 / 飞书三大聊天软件中识别效果

3一键跳转 —— 通达信 / 同花顺 / 东方财富

点击菜单上的「看通达信 / 看同花顺 / 看东方财富」，行情软件自动弹出并直达该股页面，全程无需手动输入代码：

6主要功能一览

  • 框选识别：Ctrl+Shift+左键拖拽（另两种手势可在托盘切换），屏幕任意位置，聊天记录 / 网页 / PDF / 图片均可用
  • 划词联动：选中文字松手即出菜单，微信 / 钉钉 / 飞书 / 企业微信 / QQ 全支持
  • 三端跳转：通达信原生消息通道；同花顺（经典版 / 远航版）跨进程内存消息约 0.02 秒；东方财富键盘直达
  • 多股浮条：识别结果一键锁定置顶，逐个点击对比
  • 错字容错：「谷份」「古份」「古票」等聊天错字自动纠正，5,500+ 只股票与别名词库
  • 本地识别：OCR 引擎完全本地运行，不上传任何数据
  • 完全免费：MIT 协议开源，无激活码、无试用期、无联网校验、无需联网
